An add-on for **[AutoDrive Overdrive](https://github.com/DTM-Mods/FS25_AutoDrive)**, the DTM Mods version of AutoDrive. **It needs AutoDrive Overdrive; the original AutoDrive from ModHub won't do.** It puts a green bar with an **ON/OFF button** and a **mode menu** on top of the AutoDrive window.

Use AutoDrive's **Pickup and Deliver** mode as usual: the 1st target is where it loads, the 2nd target is where it delivers. Pick a mode and switch the button ON.

### Modes

- **Fill Robot - In Stock:** set the 2nd target at a barn with a feeding robot. It fills every bin of the robot with feed from your own silos and productions, exactly what each bin still takes. It never buys: when a feed runs out it says so and goes on to the next bin.
- **Fill Robot $$$:** the same, but when your farm has none of a feed left it buys it.
- **Milk Transport:** moves every milk type from the barn (cow, buffalo, goat, mod milks) to the 2nd target, one type per load.
- **Bale Collection:** with a Courseplay bale collector, AutoDrive takes each full load to the 2nd target, drives back to the field (1st target), and Courseplay carries on until the field is clear.
- **Top It Off:** moves the selected fill type from the loading point to the tip until the tip is full. Each load is only what the tip still takes, so it never overfills. If the loading point runs out it says "Out of ...". If the tip gets full from somewhere else first, it says "Overfill detected."
- **Refuel/Repair:** drives to a diesel refuel point first, then to a workshop, using AutoDrive's own repair and refuel trips. It refuels from your own diesel storage first, then a station of your farm that sells diesel, then the nearest diesel station. Anything already at 95 % condition or fuel is skipped. Afterwards it parks at the AutoDrive parking position if you set one. Diesel only for now.

When a job ends, finished or stopped with a message, AutoDrive stops and the button switches itself OFF.

### Requirements

- **[AutoDrive Overdrive](https://github.com/DTM-Mods/FS25_AutoDrive)** (`FS25_AutoDrive.zip` from its latest release); the original AutoDrive won't do
- [Courseplay](https://github.com/DTM-Mods/FS25_Courseplay), for Bale Collection only

### Multiplayer

Works in multiplayer; the jobs run on the server. Every player needs the mod.
